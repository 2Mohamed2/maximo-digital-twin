Each one ramps in over a minute or so of real time. The twin computes the same rules as Maximo Monitor.

The station PLC sends only what it measures: the wet-well level and its rate of change, the float, pump status, power, starts and run hours, the rising main pressure and flow, and its log of the last pump cycle. Every expected value (inflow, time to spill, pump flow on the curve, power at this head, main resistance, reverse velocity, submergence) is computed from the twin file: the pump data and the station drawings.
